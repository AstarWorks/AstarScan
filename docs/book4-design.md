## 直さなかったもの（原因は分かっている）

- **720×960 の見開きを飛ばしても赤が出ない**（2 冊目 50・51、3 冊目 166・167）: 数字が 4〜5 px で読めず、「確かめられた番号」が無い。
  映像だけでは「2 枚いっしょにめくった」と普通のめくりは区別できない。1920×1080 / 1080×1920（実機のプレビュー相当、数字 8〜12 px）では赤になる。
  実機でさらに読ませるには、カメラの要求解像度を上げる（`getUserMedia` の ideal 1920×1080 → 2560×1440 以上）のが筋だが、cloud では測れないので変えていない。
- **片ページのめくりの終わり（進み 90 % 以上）で撮る**（3 冊目 143、1 冊目 single-port-wood p21）: 片ページを画面いっぱいに持つと、めくられた紙は左ページに着地し画面の外。
  32×24 の画面の変化は hold と区別がつかない（下の表。hold 中央値 2.0 / めくり 90 % 以上 2.3、ブロック最大 4.0 / 5.2）。右ページ自体は静止していて枠はページの 98 % を覆うので、撮影として正しい（採点の都合で「めくり中」）。
- **厚い本・左手の親指の見開きで、左の縁が 25 px 内側**（1 冊目 thick の 66、覆い 88 %）: モデルの読みが静止中ずっと同じ（確信度も高い）。縁への寄せ（Otsu）は机が白い本で失敗するので入れていない。保存画像では内側の余白を 3 mm ほど失うだけ。
- **明るすぎる光で左ページの上の縁が机と区別できず曲がり補正できない**（3 冊目 topnum、7〜8 / 12）: 縁の段差が 10 階調未満。縁が無いものは探せない。
